Как пользоваться

  • Слева выберите оборудование (есть поиск) — включится инструмент ＋ Поставить. Кликните по карте.
  • Зона покрытия считается сразу. Цвет — запас по сигналу.
  • Топология (вкладка «Сеть»): «Авто» — каждый абонент соединяется с лучшим ретранслятором (основная) и вторым (резервная), ретрансляторы — магистралью, mesh-узлы — с 3 соседями. На линиях: расстояние, азимут, запас. Клик по линии — профиль трассы.
  • Панели можно передвигать: тяните за полоску «⋮⋮⋮» сверху (или за заголовок окна), размер — за правый нижний угол. Двойной клик по полоске — вернуть на место.
  • Объекты можно перетаскивать мышью (инструмент ✋ Выбор). Delete — удалить выбранный.
  • 3D вверху — объёмный рельеф и здания. Вращение: правая кнопка мыши или Ctrl + перетаскивание.
  • 📏 Линейка — кликайте точки. Esc или правый клик — закончить; «Очистить» убирает линии.
  • ⛰ Профиль — две точки на карте (или два объекта): разрез местности, зона Френеля, потери.
  • Двойной клик по зданию — окно с длиной, шириной, высотой, этажностью и поворотом. Меняете цифры — здание сразу меняется в 3D. «Сохранить» — учесть в расчёте.
  • 🎯 Лучшее место — кликните центр района, укажите оборудование и мачту, «Найти». Программа переберёт крыши высоких зданий, вершины холмов и сетку точек, посчитает для каждого покрытие района с учётом рельефа и зданий и покажет лучшие 10 мест; «Поставить здесь» — установить станцию.
  • 🏗 Здание — нарисовать новое: кликайте углы, замкните кликом по первой точке (или Enter), укажите высоту.
  • Двойной клик по пустому месту карты — приблизить.
  • Все ТТХ объекта (частота, мощность, антенна, направленность, кабель, абонент) — вкладка «Объект». Общие параметры — «Настройки».
  • Вкладка «Карта»: зоны покрытия «Все / Выбранный / Скрыть» (клавиша V), прозрачность, вид карты, 2D/3D, здания, рельеф, день/ночь, подписи и линии связей.
  • «Сохранить» — файл проекта; «Открыть» — загрузить его. Проект также сохраняется автоматически.

Исходная модель (по умолчанию, как в первых версиях)

  • Потери: наибольшее из «свободное пространство» и «двухлучевая модель» (отражение от земли).
  • Препятствия: ножевая кромка МСЭ-R P.526 — самая высокая кромка рельефа или здания на трассе, с кривизной Земли (k = 4/3).
  • Здания: за каждое следующее здание на трассе — доп. затухание (настройка «Каждый след. ряд зданий»), абонент в здании — стены.
  • Запас = мощность + антенны − кабель − потери − чувствительность. Оценки: 5 ≥ 20 дБ, 4 — 10…20, 3 — 5…10, 2 — 0…5.

Реалистичная модель (по выбору в настройках)

  • Энергетика: мощность передатчика (Вт→дБм) + усиление антенн − фидер, дуплексер, разъёмы − потери на тело ≥ реальная чувствительность приёмника + запасы.
  • Длина волны: λ = 300 / f(МГц) — входит в потери свободного пространства, зону Френеля и дифракцию.
  • Отражение от земли: двухлучевая модель с эффективными высотами антенн над средним рельефом.
  • Кривизна Земли и рефракция: эквивалентный радиус k·6371 км (стандарт k = 4/3), за горизонтом — дифракция на сферической Земле (МСЭ-R P.526).
  • Рельеф: дифракция на реальном рельефе SRTM методом дельта-Буллингтона (МСЭ-R P.526-15).
  • Застройка: эмпирическая модель Окамура–Хата / COST-231 (+ МСЭ-R P.529 дальше 20 км) по типу местности; где есть здания OSM — тип определяется по плотности застройки, а высокие здания на трассе дают дифракцию через крыши; в прямой видимости потери меньше.
  • Здания и растительность: потери на стены (абонент в здании), доп. затухание на лес.
  • Атмосфера: поглощение в газах (МСЭ-R P.676), на этих частотах малое.
  • Шум эфира: индустриальный шум МСЭ-R P.372 ухудшает чувствительность (на УКВ в городе до 8–9 дБ).
  • Строгий расчёт: каждая точка зоны считается по формулам из реальных данных (мощность, антенны, частота, рельеф, здания, лес, вода, кривизна Земли, шум). Случайных добавок нет. Клик по зоне → «Подробный расчёт» показывает все слагаемые потерь в этой точке.
  • Радиус: по умолчанию «авто» — зона не обрезается кругом, а заканчивается там, где пропадает сигнал.
  • Покров местности OSM: лес (затухание по МСЭ-R P.833), вода и поля (открытая местность), жилая застройка, промзоны — меняют дальность в каждом направлении.
  • Вода: трасса над озером или морем — сигнал сильнее (гладкая отражающая поверхность, без застройки; по кривым МСЭ-R P.1546 «суша/море»).
  • Горы и холмы: за хребтом — тень (дифракция МСЭ-R P.526), зона останавливается на границе гор.
  • Оценка в баллах: 5 — отлично, 4 — хорошо, 3 — удовлетворительно, 2 — на грани, 1 — нет связи. Клик по зоне на карте — оценка в точке; клик по оценке в легенде — показать только её.
  • Статистика: запас на замирания (многолучёвость) + запас на разброс по месту для заданной надёжности (90% → +7 дБ при σ = 5,5 дБ).
  • Зона учитывает оба направления: станция → рация и рация → станция (обычно слабее рация).

Данные

  • Рельеф: AWS Terrain Tiles (SRTM, ~30 м).
  • Здания и карта: OpenStreetMap (OpenFreeMap), высоты из тегов height / building:levels.
  • Спутник: Esri World Imagery.
  • ТТХ оборудования — типовые паспортные; проверяйте по паспорту своей модификации.

Расчёт — оценочный. Для ответственных сетей подтверждайте измерениями на местности.
